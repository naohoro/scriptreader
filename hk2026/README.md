# MC Script Reader — 香港 日本産食肉加工品 商談会/交流会 2026

JWWA2026（ワールドオークション）で使った Script Reader を、香港の商談会/交流会向けに作り直したもの。

- **本番日時：** 2026年8月12日（水）18:42 開始 — 20:45 終了（香港時間）
- **会場：** Regal Kowloon Hotel 3階
- **司会：** 保呂田（日本語）／ Cindy（中文）
- **原稿：** `../台本/2026香港商談会交流会_MC構成台本.docx`

---

## 当日の使い方

### いちばん確実な方法（オフライン・推奨）

`../MC台本リーダー_香港2026_オフライン.html` の**1ファイルだけ**をスマホ/iPadに送る（AirDrop等）。
CSS・JS・台本データを全部埋め込んであるので、**電波が無くても開ける**。

### 機能

| 操作 | 内容 |
|---|---|
| 上部タブ（1〜6） | セクションへジャンプ。**定刻に入ったセクションは緑枠**で光る |
| 全員 / 保呂田 / Cindy | 自分のパートだけ濃く表示（相手のパートは薄くなる） |
| 中文 / 日本語 | UI言語の切り替え。Cindyに渡すときは中文に |
| ☾ / ☀ | ライト / ダーク |
| 編集 | その場で原稿を書き換えられる（**閉じるとリセット。保存はされない**） |
| ＋ / － | 文字サイズ7段階 |
| ▲ / ▼ | 前後のセクションへ |
| 企業紹介のリスト | **タップでチェック**。13社の呼び上げ漏れを防ぐ。カウンタと「リセット」付き |

時計は**端末のタイムゾーンに関係なく香港時間（HKT）で表示**する。
日本で開いても香港の時刻が出るので、そのまま持って行ける。

## 台本を差し替えるとき

1. `../台本/2026香港商談会交流会_MC構成台本.docx` を最新版に置き換える
2. 下記を実行

```bash
cd ScriptReader
/usr/local/bin/python3 parse_script.py   # docx → data/hk2026.json + hk2026.js
/usr/local/bin/python3 build_single.py   # 1ファイル版を再生成
```

> `python3` は **python-docx が入っている `/usr/local/bin/python3`** を使うこと。
> Homebrew版（`/opt/homebrew/bin/python3`）には入っていない。

## 原稿フォーマットの前提（パーサーの仕様）

`parse_script.py` は次の構造を前提にしている。原稿の書き方を変えるときは注意。

- 表は**1つだけ**・**2カラム**（`時間　／　司会者進行`）
- `【…】` だけの行（結合セル）＝ セクション見出し
- 台本セル内は `日：` / `中：` で言語を切り替え
- `MC：` `武内さん：` などはキュー行として扱う（本文ではない）
- `（…）` だけの行はト書き
- **企業紹介セクションだけ** `日：`/`中：` が無く、日本語行と中国語行が交互
  → かな（ひらがな・カタカナ）の有無で日本語/中国語を判定し、`1.` `2.` … の番号でペアにしている

---

## 原稿の時刻について（要確認事項）

原稿ヘッダーの表記と、進行表の実際の時刻が食い違っている。
**リーダーは進行表の時刻（18:42〜20:45）を正としている。**

| | 表記 |
|---|---|
| ヘッダー | `時間：19:00 - 21:00（受付開始 18:45）` |
| 進行表 | 18:42 スタート3分前 → 18:45 オープニング → … → 20:45 終了 |

---

## セクション見出しの中国語訳

中文モードで出るセクション名は原稿本文の語彙（「開幕辭」「參展企業」等）に合わせて作成したもので、
**原稿に元から書かれていたものではない**。変更する場合は `parse_script.py` の `SECTION_ZH` を編集する。
